# FOOD WAR

นิยายเอาชีวิตรอด ทำอาหาร สำรวจโลกหลังหายนะ ความสัมพันธ์ และการสร้างบ้านใหม่

> Canon repository for the FOOD WAR story project. เอกสารหลักเป็นภาษาไทยและอ่านได้ใน Obsidian

## เอกสาร

- [[Bible/World-Bible]] — กฎโลกในปีที่ 8
- [[Bible/Survival-Power-Bible]] — พลังพระเอกและโภชนาการส่งเสริมพลัง
- [[Story/Opening-Arc]] — โครงเรื่องเปิดเล่มแรก
- [[Story/New-World-Food-Journal]] — สมุดบันทึกวัตถุดิบและสูตรอาหารของพระเอก

## หลักการ

- ตัวเอกชายเชี่ยวชาญอาหารและการเอาชีวิตรอด ไม่ใช่ยอดนักสู้
- หญิงสาวผู้มีพลังสูงมีบทบาท ความต้องการ และเส้นทางของตนเอง
- อาหาร น้ำ และความปลอดภัยยังมีต้นทุนจริง
- การสำรวจอาหารใหม่เป็นทั้งการเติบโตของพลังและรากฐานความรู้ของอารยธรรมใหม่
- ข้อที่ยังไม่ตัดสินใจให้แสดงเป็น **OPEN** หรือ **PROPOSAL** อย่างชัดเจน

**หมายเหตุ:** เอกสารนี้เริ่มบันทึกจากการสนทนาวาง World Bible, Opening Arc และ Survival Power Bible; ยังไม่ใช่ต้นฉบับนิยายฉบับเขียนจริง
