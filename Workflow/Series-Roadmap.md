# โครงสร้างรองรับนิยายหลายเล่ม

[[00-Home|หน้าหลัก]] · [[Workflow/ChatGPT-Obsidian-Workflow|เวิร์กโฟลว์]]

## โฟลเดอร์ที่ใช้เป็นมาตรฐาน
- `Chapters/Volume-01/Chapter-XX.md` ต้นฉบับตอนเผยแพร่จริง; เปิด `Volume-02/` เมื่อเริ่มเล่มใหม่
- `Bible/` กฎพื้นฐานที่ห้ามขัด
- `Characters/` แฟ้มตัวละครและความเปลี่ยนแปลง
- `Locations/` สถานที่และเส้นทาง
- `Systems/` พลัง กลไก และการเติบโต
- `Story/` เส้นเวลา ปม แผนเรื่อง บันทึกวัตถุดิบ
- `Workflow/` วิธีใช้ ChatGPT/Obsidian, checklist, การตัดสินใจ
- `Templates/` แม่แบบสร้างแฟ้มใหม่
- `Notes/` ใช้สำหรับโน้ตตอนหากจำเป็น (Git ไม่เก็บโฟลเดอร์ว่าง)
- `Assets/` รูปภาพและแผนที่ที่ผู้เขียนเลือกยืนยันให้เก็บใน Repository

## สำหรับเล่มต่อไป
สร้าง `Chapters/Volume-02/Chapter-Index.md` และไฟล์ `Chapter-01.md` เฉพาะเมื่อเริ่มจริง; คงเลขตอน **ภายในแต่ละเล่ม** และใช้ลิงก์เต็มแบบ `[[Chapters/Volume-02/Chapter-01]]` ป้องกันซ้ำชื่อ
เพิ่มสถานะ `first_appearance`/ความสัมพันธ์/แผลตามเล่มในแฟ้มตัวละคร ไม่สร้างแฟ้มชื่อซ้ำโดยไม่จำเป็น

## แนวทางการใช้งาน Graph
Graph ที่ใหญ่จะรกเร็ว: ใช้ Local Graph จาก [[00-Home]], [[Characters/Character-Index]], [[Locations/Location-Index]], [[Systems/Power-Index]] เพื่อดูความเชื่อมโยงตามหัวข้อ. ใช้ Properties และ Search ช่วยกรอง `type:`, `status:`, `tags:`.

## ป้องกันการปะปนความจริงกับแผน
**FACT** = เกิดในนิยายแล้ว; **CANON** = กฎที่อนุมัติ; **PLANNED** = ตั้งใจให้เกิดแต่ยังแก้ได้; **OPEN** = ยังไม่รู้; **PROPOSAL** = แนวคิดรอพิจารณา; **APPROVED** = ตอนผ่านคำอนุมัติแล้ว

อย่ากำหนดปีปฏิทินหรือวันเดินทางที่นิยายไม่ได้บอก; เมื่อมีข้อมูลใหม่ให้ปรับแฟ้มตามหลักฐานตอนที่เผยแพร่
