# Checklist ก่อนเผยแพร่และหลังเขียน

[[Workflow/ChatGPT-Obsidian-Workflow|คู่มือ]] · [[Bible/World-Bible|กฎโลก]] · [[Bible/Survival-Power-Bible|กฎพลัง]]

## ก่อนเขียน
- [ ] อ่านตอนล่าสุดและ [[Story/Timeline]] เพื่อทราบสภาพตัวละคร/วัตถุดิบ/เวลา
- [ ] ตรวจ [[Story/Plot-Threads]] ไม่สร้างคำตอบให้ปมโดยไม่มีการค้นพบ
- [ ] ตรวจ [[Story/Knowledge-Matrix]] ว่าใครรู้เรื่องใด และ [[Story/Food-Register]] ว่าวัตถุดิบไหนยังไม่ปลอดภัย
- [ ] ตรวจว่า PLAN ใน [[Story/Future-Arc-Plan]] ไม่ถูกนับเป็น FACT
- [ ] กำหนดว่าแต่ละฉากใครรู้/ไม่รู้เรื่องใด

## ความต่อเนื่องภายในตอน
- [ ] จำนวนสมาชิกและชะตาของทีมไม่ขัดกับตอนก่อน
- [ ] ที่ตั้ง/ระยะเดินทาง/จุดถอนตัวมีเหตุผล
- [ ] น้ำ อาหาร การขน/การเก็บและสุขอนามัยมีต้นทุนจริง
- [ ] พลังของแต่ละคนใช้ตรงชนิดและต้นทุน; อีธานยังไม่รู้จักมิติก่อนช่วยคาริน
- [ ] หากถึงช่วงโจมตี เดเร็ก คาริน บรัม และคนอื่นป้องกัน/อพยพอย่างมีเหตุผล; ไม่มีการจงใจทิ้งอีธานหรือคาริน
- [ ] อีธานย้อนกลับไปช่วยคารินด้วยตัวเองก่อนพบมิติ; จุดค้นพบเกิดตอนพยายามเก็บเนื้อสัตว์โลกใหม่ที่คารินฆ่าหลังช่วยแล้ว
- [ ] ชะตาผู้รอดชีวิตรายบุคคลคง OPEN จนฉาก/ตอนเผยแพร่ยืนยัน
- [ ] ไม่ตั้งชื่อสัตว์หรือพืชใหม่ก่อนตัวละครพบและตรวจจริง
- [ ] การบาดเจ็บและเวลาฟื้นตัวไม่หายเองโดยไร้เหตุผล

## ภาษาและอารมณ์
- [ ] ไม่มีสรรพนาม “ข้า–เจ้า” ในบทสนทนาปกติ
- [ ] บทพูดฟังเหมือนคนคุยกันจริง มีเสียงเฉพาะคน ไม่ใช่ถาม-ตอบ “ดี/ครับ/ใช่” ซ้ำ
- [ ] ไม่ให้ทุกบทพูดอธิบายบทเรียน/Canon; ใช้การกระทำและความเงียบให้เกิดอารมณ์
- [ ] จังหวะรักช้า ไม่เร่งสารภาพหรือดราม่าก่อนปูพื้น
